# Vídeos de demonstração

Os arquivos são trailers/teasers dos projetos abertos do Blender, em áudio original e sem cortes. O teaser de Elephants Dream foi recodificado para reprodução nos navegadores, conforme indicado abaixo. As capas SVG são ilustrações próprias do VisionBox. Os trailers estão identificados como tais no catálogo; não são os filmes completos. NR significa classificação não informada.
